# Projeto-acad-mico---JOGO-SUPER-TRUNFO-
Projeto acadêmico de um jogo chamado Super Trunfo! o jogo consiste em cartas de países e cada país tem seus subtópicos, como por exemplo, o nome do estado, a cidade, número da população etc. o objetivo do jogo é comparar as cartas, vencendo aquela com os maiores subtópicos em relação as outras. 

* projeto desenvolvido durante as aulas da faculdade de Análise e desenvolvimento de sistemas na linguagem C!
* projeto em andamento!
